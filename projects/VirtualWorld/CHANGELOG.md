# Changelog

Notable user-visible changes will be recorded here. This project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) style, but a stable
versioning policy has not yet been announced.

## [Unreleased]

### Added

- Cross-platform virtualization backend registry and capability reporting for
  Windows x86-64/ARM64, macOS x86-64/ARM64, Linux x86-64/ARM64/RISC-V64, and
  HarmonyOS/OpenHarmony compatibility targets.
- Honest native, hardware-accelerated, and QEMU TCG fallback tiers.
- QEMU/UTM/VirtualWorld configuration import and export.
- Mini vMac-compatible System Software 0-6 runtime path.
- English and Simplified Chinese project documentation.
- GPL-2.0-only project license and release-compliance documentation.

### Security

- Signed Support Disk manifests, expiry and digest validation, and separate
  authorization for high-risk host operations.
