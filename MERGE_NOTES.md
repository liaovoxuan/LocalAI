# LocalAI edition merge

- `local_ai.py` is now the single full implementation for Standard, Pro and Ultra.
- `local_ai_pro.py` and `LocalAI_Ultra.py` are compatibility launchers only.
- New installations start with all Pro/Ultra features enabled for free.
- Settings no longer requires edition activation.
- Activation codes are ignored for compatibility with older configs.
- OpenAI-compatible providers, the official OpenAI provider, and the Ultra web feature profile are available directly.
